03Plug in your own agent

Two ways, no changes to this tool.

Your agent drives its own browser. Start an episode, point the agent at the URL, then ask for the grade.

./polarbench serve --port 5055
POST /api/episode/start  {"task": "t01_qualify_priya", "seed": 0}
  → {"start_url": ..., "prompt": ...}
POST /api/episode/finish → {"passed": true, "reason": ...}

Your agent is a Python class. It gets the page and returns one action, and polarbench drives the browser.

class MyAgent:
    def reset(self, task, seed): ...
    def step(self, obs, obs_text, last_result):
        return {"action": "click", "id": 12}, "why"
